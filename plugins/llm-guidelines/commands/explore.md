Explore the community LLM reporting guidelines.

Use the `llm-guidelines` skill in **explore mode**: answer questions about the guidelines, discuss study design, weigh design choices, navigate the scope statement and the study-type taxonomy, walk through the checklist before any draft exists.

Load only the bundled files relevant to each question (`scope.md`, `study-types/<slug>.md`, `guidelines/<slug>.md`, `checklist.md`); cite them and use the same RFC 2119 levels (**must**, **should**) the underlying guideline uses.

Do not write a report file. If a draft already exists and the user wants a structured pass over it, switch to `/llm-guidelines:review`.
