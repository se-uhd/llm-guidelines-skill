# LLMs as Tools for Software Engineering Researchers

LLMs can serve as tools to help researchers conduct empirical studies. They can automate various tasks such as data collection, pre-processing, and analysis. For example, LLMs can apply predefined coding guides to qualitative datasets ([*LLMs as Annotators*](../study-types/llms-as-annotators.md)), assess the quality of software artifacts ([*LLMs as Judges*](../study-types/llms-as-judges.md)), generate summaries of research papers ([*LLMs for Synthesis*](../study-types/llms-for-synthesis.md)), or simulate human behavior in empirical studies ([*LLMs as Subjects*](../study-types/llms-as-subjects.md)). If LLMs could complete these tasks well enough, they would reduce the time and effort required to conduct a study. However, these applications each pose challenges to validity and reproducibility.
