# LLMs as Tools for Software Engineers

LLM-based assistants have become a widely adopted tool for software engineers (Stack Overflow 2025), supporting them in various tasks such as code generation and debugging. Researchers have studied how software engineers use LLMs ([*Studying LLM Usage*](../study-types/studying-llm-usage-in-software-engineering.md)), developed new tools that integrate LLMs ([*LLMs for Tools*](../study-types/llms-for-new-software-engineering-tools.md)), and benchmarked LLMs for software engineering tasks ([*Benchmarking LLMs*](../study-types/benchmarking-llms-for-software-engineering-tasks.md)).
